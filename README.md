# SnapGuard: On-Device AI Face Liveness Detection

## Overview

SnapGuard is an AI-powered face liveness detection solution designed to distinguish a live person from presentation attacks such as photographs, screen-displayed images, and replayed videos.

The project focuses on real-time, on-device AI inference on Snapdragon-powered HP PCs, reducing dependence on cloud processing and unnecessary transmission of camera data.

## Problem

Face-based verification systems can be vulnerable to presentation attacks where an attacker presents a photo, video, or screen image instead of a live person.

SnapGuard addresses this challenge by analyzing facial and visual cues to determine whether the detected face is likely to belong to a live person.

## Proposed Solution

SnapGuard combines:

- Face detection
- AI-based liveness analysis
- Real-time camera processing
- Lightweight on-device inference
- Simple and accessible user interface

The solution is designed with Snapdragon-powered PCs in mind, with emphasis on efficient local AI execution.

## Key Innovation

The key focus of SnapGuard is performing face liveness analysis locally on the user's PC instead of relying primarily on cloud-based inference.

This approach aims to reduce network dependency, improve responsiveness, and support privacy-conscious camera-based verification.

## Target Applications

- Secure face-based authentication
- Identity verification
- Access-control support systems
- Privacy-conscious AI applications
